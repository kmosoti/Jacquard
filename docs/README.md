# Documentation

## Source of Truth

In order of authority:

1. [Product contract](PRODUCT-CONTRACT.md): what Jacquard promises.
2. [Decisions](decisions/README.md): accepted ADRs.
3. [Architecture](architecture/README.md): views of what exists, with diagrams.
4. [Current state](CURRENT.md): active milestone, assumptions, risks, open decisions.
5. [Research](research/README.md): dated, sourced findings that motivated decisions.

The [glossary](glossary.md) fixes the vocabulary all of these use. Code is evidence of what exists; a disagreement between a document and the code is reconciled explicitly, never by silently editing either.
