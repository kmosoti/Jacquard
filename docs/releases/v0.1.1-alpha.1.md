# Jacquard `v0.1.1-alpha.1`

Security remediation and hardening release across the factory CLI, browser renderers, Loom workspace preparation, `products/cockpit`, `jacquard-xtask` verification gates, and release provenance pipeline.

## Highlights

### Swatch & Loom Boundary Containment
- Added `SwatchSource::validate` and `SwatchSource::validate_path` in `jacquard-ports` rejecting empty, rooted/absolute, backslash, `:`/drive-prefix, control/NUL, `.`/`..` paths and missing `entry`, plus `<= 512` file and `<= 32 MiB` byte bounds.
- Replaced symlink-following directory traversal in `jacquard` CLI (`swatch_loader`) with `symlink_metadata`, physical canonical containment, file identity checks, and non-regular file rejection.
- Hardened `jacquard-loom-claude::prepare` to reject tracked/untracked symlinks and non-regular files via `symlink_metadata` + canonical containment, and exclude sensitive untracked filenames (`.env`, `.env.*`, `*.pem`, `*.key`, `*secret*`, `*credential*`, `*token*`, `.npmrc`, `.netrc`, `id_rsa*`, `id_ed25519*`).

### Renderer Isolation & Unforgeable Probe Integrity
- Replaced `file://` Swatch loading in `jacquard-renderer-chrome` with an ephemeral `127.0.0.1:0` loopback HTTP server, `0700` no-follow scratch materialization, per-launch isolated `0700` `--user-data-dir`, non-loopback DNS/proxy blocking, and default-enabled Chromium sandbox (`JACQUARD_ALLOW_NO_SANDBOX=1` explicit opt-in for restricted CI containers).
- Replaced `postMessage` / candidate-DOM `#jacquard-probe` reading with `<iframe sandbox="allow-same-origin">` + `script-src 'none'` candidate isolation inside a one-shot, CSP-locked (`script-src 'nonce-...'`), unguessable outer wrapper that removes its inline script tag before framing, tears down the candidate iframe and sanitizes parent DOM nodes before emission, and authenticates `<script type="application/json" id="jacquard-probe-{nonce}" data-sig="{hmac}">` with pure-JS zero-prototype HMAC-SHA256 verified in constant time in Rust.
- Added same-origin `context.route("**/*", ...)` request blocking, non-loopback resolver/proxy flags, and CDP `Page.createIsolatedWorld` + `Runtime.evaluate` probe execution in `jacquard-renderer-playwright/src/render.mjs` (and `perf.mjs`), isolating probe evaluation from main-world prototypes without disabling product WASM/WebGL hydration.

### Cockpit Wiki XSS & Layout DoS Hardening
- Updated `cockpit-wiki/src/markdown.rs` to collect nested inline/link events inside `Tag::Image` into a plain-text buffer and HTML-escape once into `alt="..."`, and tightened `cockpit-wiki/src/sanitize.rs` to reject whitespace, quotes, angle brackets, backslashes, and control characters in URLs.
- Enforced Mermaid flowchart budgets (`<= 16 KiB`, `<= 64` nodes, `<= 128` edges, `<= 128` label chars, `<= 32` zones) in `cockpit-wiki/src/highlight.rs` prior to `iso-diagram` layout while preserving the `< 256,000` byte WASM hydration bundle budget and downstream `green-infra` API compatibility.

### Verification Gates & Release Provenance
- Hardened `jacquard-xtask` `mutants` and `trust` checks to reject empty corpora and detect deleted or weakened entries in `tests/semantic-mutants/corpus.toml` without `Trust-Boundary: escape-hatch`.
- Upgraded `jacquard-xtask` `purity` checks with Rust lexical tokenization (ignoring spoofed attributes inside comments/strings), `#[path]`/`include*!` `src/` containment, workspace `[lints] workspace = true` + `unsafe_code = "forbid"` verification, and token-level `std` detection (`use std`, `::std::`, `extern crate std`).
- Split `.github/workflows/release.yml` into unprivileged `build` (`contents: read`) and minimal `publish` (`contents: write`, `id-token: write`, `attestations: write`), enforcing `origin/main` ancestry, tag-to-`Cargo.toml` version verification, SHA-pinned actions, and Chrome sandbox probing.
