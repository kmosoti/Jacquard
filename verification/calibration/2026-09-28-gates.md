# Gate Calibration, Milestone 02

- **Date.** 2026-09-28
- **Method.** Hand-injected defects, one at a time, in a scratch copy of the working tree, each followed by `cargo test -p jacquard-xtask --test gates`. This is not a `cargo mutants` run; the scheduled mutation run is not set up yet. A baseline run with no defect passed 6 of 6 before the probes that count below.
- **Harness note.** The first pass restored files with `mv`, which left their modification times older than the build and let cargo reuse a mutated binary. Those results were discarded; every result below is from the second pass, which touches each restored file.
